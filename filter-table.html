Filter Table

A table visual for Power BI with a search and value filter under every column. Readers find their own rows, and because the filters are real report filters, the rest of the page follows.

Try each feature

Each button runs the feature in the live table above, the way a reader or author would.

  • A filter under every column

    Text columns get a value list with search, numbers get a range, dates get a from and to.

  • Every active filter in view

    Each filter shows as a chip above the rows, and each one clears on its own.

  • Search the whole table

    One box searches every column at once and narrows only this table.

  • Freeze key columns

    Keep the first columns in place while the rest scroll sideways.

  • Readers arrange their own view

    Drag any header to move a column, and show or hide columns from the Columns menu.

  • Group rows with subtotals

    Group by any field, with a subtotal under each group.

  • Pages for long tables

    Page through rows, or let long tables scroll smoothly with virtual scrolling.

What Power BI receives

Each filter you set in the demo is sent to the report as a standard Power BI JSON filter. This is the exact payload, live.


      

    

  


  

    

      

        
What it does

        All of it free. Nothing needs a server or an account.
      

      

            

              
              
AreaWhat you get

              
                
Column filtersA value list with search and Blank for text, a range or value search for numbers, a from and to for dates. Active filters show as chips you can clear one at a time.

                
Report filteringColumn filters are applied as Power BI filters, so other visuals respond and bookmarks restore them. A separate search bar filters only the table.

                
Totals and groupingTotals with an aggregation chosen per column, grouping with subtotals, and rates and percentages that are never summed by accident.

                
Formats and colourModel formats kept, with per-column overrides. Conditional colours with a lower is better option, data bars, and five style presets: Modern, Corporate, Minimal, Midnight and Ledger.

                
LayoutFrozen columns, column move and resize by dragging, hidden columns, saved layouts and pagination or virtual scrolling.

                
RowsRow selection that cross-highlights the report, copy, and CSV export through Power BI's own download service.

                
Large tablesLoads 30,000 rows at a time and can fetch more on request or automatically.

                
AccessibilityKeyboard sorting and row navigation, Escape closes any popup, sort state announced to screen readers, and full support for high contrast mode.

Good to know

      

      

          

            
Measures

            
Filters on measures cannot become report filters in Power BI. They still filter the table, and the status bar says so.

            
Reading view

            
Readers can filter, sort, resize and move columns, but Power BI does not let them save changes. Anything that should stick for everyone is set by the author in edit mode.

            
Exporting

            
CSV export uses Power BI's download service, so it follows your organisation's export settings.

            
Privacy

            
The visual makes no network requests and collects nothing. Read the privacy policy.
