Common questions

Why does my filter not change the other visuals?

Only columns from your model can become report filters. If the column is a measure, the filter still narrows the table, and the status bar under the table says it applies to this table only.

Also check the edit interactions between Filter Table and the other visual in Power BI Desktop (Format, Edit interactions). If they are set to None, the filter will not reach that visual.

My column order and widths reset for readers. Why?

Power BI does not let readers save changes to a visual in reading view. Set the layout in edit mode and save the report; that layout is what everyone sees. Readers can still rearrange columns for their own session.

The table stops at 30,000 rows.

Power BI sends data to visuals in segments. Filter Table shows a Load more button, or loads the rest automatically if you turn on Load all rows automatically in the Interactions card.

Export to CSV does nothing.

Export goes through Power BI's download service, which follows your organisation's export settings. If an admin has turned off export for custom visuals, the button cannot save a file. Ask your Power BI admin.

Totals look wrong for a rate or percentage column.

Open the Specific column card, pick the column, and set its Aggregation to Average, Minimum, Maximum or None. Rates and percentages should rarely be summed.

Will an update break my saved reports?

No. Updates keep the visual's identity and carry existing settings forward, including settings saved by older versions.

Does it send my data anywhere?

No. The visual makes no network requests and collects nothing. See the privacy policy.
