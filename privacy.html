Privacy Policy

Effective 14 August 2026 · Applies to the Filter Table custom visual for Microsoft Power BI
The short version: Filter Table runs entirely inside Power BI on your machine or browser. It makes no network calls, collects no data, and sends nothing to us or to anyone else.

What the visual does with your data

Filter Table displays data that Power BI supplies to it inside Power BI's sandboxed visual environment. All filtering, sorting, grouping, formatting and rendering happens locally within that sandbox. The visual contains no analytics, telemetry, tracking or error-reporting code and communicates with no external servers.

What the visual stores

  • Layout settings (column order, widths, hidden columns) and formatting choices are saved into the Power BI report file itself, using Power BI's standard settings mechanism. They stay wherever your report is stored and are governed by your organisation's Power BI arrangements with Microsoft.
  • CSV export is only ever started by you, and the file is produced through Power BI's own download service to your device. We never see it.
  • Copy actions place cell or row text on your local clipboard only.

What we collect

Nothing. We have no servers, no accounts, no cookies and no way to observe your usage of the visual. If you email us for support, we will see whatever you choose to include in that email and use it only to help you.

This website

This site is a set of static pages hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub, as the hosting provider, may keep standard technical logs (such as IP addresses) as described in GitHub's privacy statement.

Changes

If the visual's behaviour ever changes in a way that affects this policy, we will update this page and the effective date above before releasing that version.
