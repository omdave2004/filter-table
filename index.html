The table your report readers can actually filter.

Filter Table puts a search box and a value picker under every column header, so anyone reading the report can narrow the data without touching slicers or the filter pane. Sorting, grouping, totals and CSV export included.

Features

Per-column filters

A search box under every header. Text columns get a multi-select value dropdown, numbers get min/max or value search, dates get a from/to range.

Filters the whole report

Column filters apply as real Power BI filters, so your other visuals respond to them just like slicers.

Global search

One box that searches every visible column at once, with filter chips that show exactly what is active.

Cross-filter selection

Click rows (Ctrl and Shift work as you expect) to highlight matching data in the rest of the page.

Grouping and totals

Group by any column with collapsible sections and subtotals, plus an overall totals row for numeric columns.

Five style presets

Modern, Corporate, Minimal, Midnight and Ledger. One dropdown restyles the entire table, or keep Modern and set your own colours.

Layouts that persist

Column order, widths and hidden columns are saved into the report itself, so the layout survives refreshes and travels with the file.

CSV export

Export the filtered result, not the raw table, with a single button. Copy single cells or whole selected rows from the right-click menu.

Frozen columns and paging

Pin up to five columns to the left edge, paginate large results, and drag column edges or headers to resize and reorder.

Conditional formatting

Colour numeric cells against a fixed target, a percentage of the column maximum, or simple positive/negative rules. Optional in-cell data bars.

Hyperlinks that work

URLs in your data render as safe, clickable links that open through Power BI's own link handling.

Accessible by default

Keyboard sorting and selection, screen-reader sort states, high-contrast mode support and report-page tooltips.

Install

  1. Get the file. Download the latest .pbiviz from the link below, or wait for the AppSource listing to go live.
  2. Import it. In Power BI Desktop, open the Visualizations pane, choose the three-dots menu, then Import a visual from a file and pick the downloaded file.
  3. Add your data. Drop the new icon onto the canvas and drag any fields, text, numbers or dates, into the single Columns bucket.
  4. Make it yours. Everything else lives in the Format pane: style presets, filters, grouping, totals, pagination, export and more.
For organisation-wide deployment, a Power BI administrator can add the same file under Admin portal > Organizational visuals, which makes it available to every report author in the tenant.

Questions

Does my data leave Power BI?
No. The visual runs entirely inside Power BI's sandbox and makes no network calls. Nothing is collected, transmitted or stored outside your report. See the privacy policy.
Is there a row limit?
Power BI supplies custom visuals with up to 30,000 rows. When the limit is reached the status bar says so. For readability, the table renders up to 1,000 rows at a time unless pagination is on; filtering, totals and export always cover everything.
Do the column filters affect other visuals?
Yes, they are applied as standard Power BI filters on the page, and row selection cross-highlights the rest of the page the same way built-in visuals do.
Will saved layouts follow the report?
Yes. Column order, widths and hidden columns are stored in the report file itself, so they persist across refreshes and for anyone who opens the report.
Is it certified?
The visual targets AppSource listing first. It already passes the platform's validation tooling; Microsoft certification is a separate program we may pursue later.
