How the filters work

The table above is the real visual, not a mock up
Under every column
Text columns get a value list with search and a Blank option. Numbers get a range or a value search. Dates get a from and to. Active filters show as chips above the rows.
Real report filters
Selections go to Power BI as report filters, so cards, charts and other visuals respond as they would to a slicer, and bookmarks save them. A table-only search bar is there for quick lookups that should not touch the report.
Set up per column
Choose the aggregation for each column, so rates and percentages are never summed by accident. Keep the formats from your model, or override them. Add conditional colours that know when lower is better.
Built for big tables
Sorting, grouping with subtotals, totals, frozen columns, column move and resize, row selection, CSV export, and loading beyond 30,000 rows when you need them.
